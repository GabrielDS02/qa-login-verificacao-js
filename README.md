# QA Login Verificação JS

Repositório do trabalho estudantil de **Quality Assurance (QA)** com foco em testes e documentação de um sistema de login com validação de campos em JavaScript.

## 📌 Contexto

Este projeto faz parte das atividades do curso **Técnico em Desenvolvimento de Sistemas** da instituição **Proz Venda Nova**.

O trabalho foi realizado em duplas, com o objetivo de aplicar conceitos de **qualidade de software**, realizando testes no projeto de outra dupla e produzindo documentação técnica sobre o sistema testado.

## 🎯 Objetivo

- Testar o sistema de login desenvolvido por outra dupla.
- Documentar o funcionamento, os casos de teste e as validações existentes.
- Receber documentação semelhante sobre o nosso próprio sistema.
- Praticar a troca de feedback técnico entre equipes de desenvolvimento.

## 🧪 Sistema Testado

O sistema de login testado é uma aplicação simples com **verificação de campos de input em JavaScript**.

As validações observadas incluem:

- Verificação de campos vazios
- Validação de formato de e-mail
- Verificação de quantidade mínima de caracteres na senha
- Exibição de mensagens de erro para o usuário
- Feedback visual durante a interação

## 🚀 Como executar os projetos

Os projetos são simples e podem ser executados diretamente no navegador.

1. Acesse a pasta do projeto desejado.
2. Abra o arquivo `index.html` no navegador.
3. Interaja com o formulário de login para ver as validações em ação.
